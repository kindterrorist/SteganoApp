# Image Steganography App

Hide secret messages inside images using LSB steganography!

## Features

- ✨ Encode text messages into images
- 🔍 Decode hidden messages from images
- 🎨 Beautiful modern GUI
- 🔒 Works with PNG, JPG, BMP images

## Download

Download the latest version from [Releases](https://github.com/kindterrorist/Steganoapp/releases)

## How to Use

### Encoding:

1. Click "Select Image"
2. Type your secret message
3. Click "Encode & Save"
4. Save as PNG file

### Decoding:

1. Click "Select Encoded Image"
2. Click "Decode Message"
3. View the secret message!

## Installation (for developers)

```bash
pip install -r requirements.txt
python main.py
```
